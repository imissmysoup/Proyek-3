# Interactive Profile Card (Task D4)

Proyek ini mendemonstrasikan implementasi antarmuka profil interaktif menggunakan Vanilla JavaScript, mencakup manipulasi DOM, Event Handling, dan Fetch API (Asynchronous JS).

## Cara Menjalankan
1. Buka *folder* proyek ini di Visual Studio Code.
2. Pastikan ekstensi **Live Server** sudah terpasang.
3. Klik kanan pada file `index.html` dan pilih **"Open with Live Server"**.
4. Proyek akan terbuka secara otomatis di *browser* pada alamat `http://127.0.0.1:5500/`. Jangan membuka *file* HTML langsung dengan klik ganda di *File Explorer* karena akan menyebabkan *error* CORS pada Fetch API.
